# 研究规则修正 V2 — MT5 侧（2026-09-05，用户授权）

> 用户原话：「可以打破之前对于 MT5 的规则限制，当时限制的可能太多……你来开始吧。」
> 本修正只改 MT5 侧的**范围**限制，不改研究纪律。目的：把 A 股 V25 之所以能出第一个 Level-1 的方法（大截面 × 多层信息 × 一个预注册模型），搬到 MT5 上能用的对象。

## 保留（不因本修正改变）

1. 预注册：合同先写、假设/特征/参数/账本/门全部事前固定；跑完冻结；任何改动 = 新合同、计 FDR 的 m。
2. 成本模型必须来自**实测**（点差按 bar 的 spread 列、隔夜利息按 `swap_mode`/`swap_long`/`swap_short`），不许假设零成本。
3. 非重叠资金账本、FDR、5 个滚动验证窗（≥4/5）、超额序列判独立。
4. 无正的独立验证账本 → 不 Paper、不 Live；任何时候不 `order_send`。
5. 不改历史 evidence；不覆盖 `20260825`/`20260828`/`20260829` 冻结数据；`FINAL_OOS_READ.json` 类锁继续有效。
6. **不重开已证伪家族**：XA / RT / XR / IT / TS / MS / RI / AMS / IV / POS / INV / RATES / CARRY / SUP / CM / UM / BREADTH / SIZE / V10 62 实验 / V11 / OI / DTE / TERM_STRUCTURE。这些是在少数宏观品种上、逐条规则式做的，结论不变；本修正不允许"换个参数再来一次"。

## 解除（MT5 侧）

| 旧限制 | 新规则 | 理由 |
|---|---|---|
| ML 禁令（源于 V10/V14：十几个宏观 CFD 的价格上找模型） | **允许**在 ≥300 只的截面上用一个预注册模型（A3） | V1 修正已指出该禁令的证据范围不覆盖大截面；V25 证明大截面 × 模型能过门 |
| `#` 股票 CFD「只做 inventory」 | **允许**把 `CFD-Shares\USA`（497 只）当研究截面 | 这是 MT5 里唯一有截面宽度的对象；FX/商品只有 ~60 个品种，没有截面 |
| 只做多头绝对收益账本 | **允许**事前登记 LS（多空、美元中性）账本为闸门 | 股票 CFD 多头隔夜利息 ≈ 11%/年，短头 ≈ 0.9%/年（实测），多头绝对账本结构性吃亏；LS 是对费率诚实的账本 |
| 不下载新 MT5 数据 | **允许**从本机终端拉 D1（$0）；仍禁止付费 tick / 期权 | 终端自带 |

## 新增硬约束

- **幸存者偏差**：MT5 只提供当前挂牌的 497 只，退市/被并购的不在。所有 V30 结果标 `UPPER_BOUND_SURVIVORSHIP`；即使过门也**不得**直接 Paper，必须先在无幸存者偏差的宇宙（免费：EDGAR 历史 CIK 列表 / 指数历史成分）上复现。
- **信息层顺序**（每层一个模型，A3）：V30 价格层 → V31 EDGAR 基本面（filing date PIT）→ V32 Form 4 内部人 / FINRA 空头利息。上一层没跑完冻结，不开下一层。
- **样本短**（大多数 2018-11 起）：滚动窗按日历年（2021/2022/2023/2024/2025-26），5 窗 ≥4 正；不许因为短就放松。
- 10% 不是门；本修正不是为了 10% 调参。
