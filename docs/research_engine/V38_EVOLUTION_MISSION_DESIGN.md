## 2. 三条工作线

### S0 外部学习 → 假设账本（不直接改代码）

- 来源：A 股学术（Liu–Stambaugh–Yuan CH-3/CH-4；A 股异象综述；PEAD / 内部人交易 / 回购 / 解禁 / 大宗 文献）、聚宽 / 掘金 / 雪球有回测过程的帖子、券商金工公开报告、东财数据中心可免费拉的表。
- 每条想法登记到 `V38_HYPOTHESIS_LEDGER.md`：来源、机制、数据表、PIT 口径、**对照 `FAILURE_ATLAS.json` 81 行去重结果**、状态。
- 论坛帖子只当"想法来源"，不当证据；任何帖子里的回测收益一律不信。

### S1 新信息层（免费、ATLAS 未覆盖、文献有机制）

按 文献强度 × 数据可得 × 新颖度 排序，逐层做，**每层一个预注册模型，跑完冻结**（Amendment V1 A3）：

| 序 | 层 | 机制 | 东财数据中心表（待 S0 核实） | ATLAS |
|---|---|---|---|---|
| L1 | 高管 / 大股东增减持 | 内部人净买入 → 未来超额（文献最强的免费信号之一） | 高管持股变动 / 股东增减持明细 | 未覆盖 |
| L2 | 上市公司回购 | 回购公告 / 实施 → 正漂移 | 回购明细 | 未覆盖 |
| L3 | 限售解禁 | 解禁前后负漂移 → 作**排除项**（不能做空） | 解禁明细 | 未覆盖 |
| L4 | 业绩预告 / 快报 | 事件早于定期报告；PEAD（区别于 V16 年报 / V27 季报） | 业绩预告 / 业绩快报 | 未覆盖（V16/V27 是定期报告） |
| L5 | 大宗交易 | 折价率 / 成交量 → 信息含量 | 大宗交易明细 | 未覆盖 |
| L6 | 公募基金季报持仓 | 拥挤度 / 增持变动（季度 PIT） | 基金重仓明细 | 未覆盖 |
| L7 | 股权质押 | 高质押比例 → 负漂移 → 排除项 | 质押统计 | 未覆盖 |
| L8 | 散户情绪复合（用户问的"韭菜指数"） | 市场级：融资余额变化 + 换手 z + 涨停/连板家数 + 中登新增投资者 + 龙虎榜营业部净买；个股级：换手异常 + 龙虎榜出现 | 多表 | 部分覆盖（融资 V23 / 换手 H07–H09 已为 CS 因子）；**作为市场级情绪指数**未测 → 归入 S2 作仓位规则输入，不作 CS 因子 |

每层统一流程：`contract → download（东财 datacenter，Clash 代理）→ normalize（PIT：公告日后首个交易日可见）→ features（固定，不搜）→ build_scores（V25 引擎，同一 LightGBM 配置）→ evaluate_signal（LO20 事前登记账本 / HN20 仅当机制是对冲）→ 5 滚动窗 → 超额-vs-EW corr vs ML1（<0.90 才算独立）→ 判决 → ATLAS 行`。

**事前判决标准（每层相同）**：验证期 LO20 资金正 且 超额 vs EW t ≥ 2 且 滚动 ≥4/5 且 corr vs ML1 < 0.90 → `INDEPENDENT_CANDIDATE`；否则 `NO_CANDIDATE` 或 `SAME_CLUSTER`。不降门、不换账本、不因"差一点"重跑。

### S2 组合层（外壳级，用户已允许各测一次）

作用于 V26.8 外壳的账本，不改名单、不改 ML1：

| 合同 | 规则（事前写死） | 判决 |
|---|---|---|
| O1 趋势仓位 | 主板等权指数收盘 < 200 日均线 → 下一期仓位 50%，否则 100% | 研究期先读；验证期一次 |
| O2 波动率仓位 | 账本 20 日已实现波动 > 研究期中位数 × 1.5 → 下一期仓位 50% | 同上 |
| O3 情绪仓位（L8 输出） | 市场情绪指数 > 研究期 90 分位 → 下一期仓位 50%（过热减仓） | 同上，只在 L8 指数建好后 |

**事前判决**：验证期 **MaxDD 改善 且 夏普不低于现状** 两者同时成立才采纳；只改善一个 = 不采纳。三条各算一次，共计 m=3。采纳的规则写进 `daily.py` 需再走一次五阶段。

### S3 组合

只有 S1 出现 ≥1 个 `INDEPENDENT_CANDIDATE` 才做：ML1 + 新袖等权（不优化权重），一次读验证期。

## 3. 纪律（全部继承，无例外）

- 固定划分：研究 2012-01→2021-08，验证 2021-08→2024-03，**禁用窗 2024-03→2026-08 不读**（V28 已消耗）。
- 每个信息层一个模型；特征表事前写死；不搜参；跑完冻结。
- FDR：V38 统一记 m（S1 每层 +1，S2 每条 +1），最终 BH 报告。
- 不重开 ATLAS 已覆盖对象；每层动手前先查。
- 近期窗 / 一月一季不读；"最近"看 V29 影子账本。
- 不为改善数字改 ML1 任何东西；不加个股出场规则（V34）。
- 只有正的独立账本才谈 Paper；Paper / 实盘由用户定。
- 数据：免费优先；付费先报价，余额 ≈$46 不自动花。

## 4. 节奏与停止

- 跨多次会话；**每完成一层出一份判决 + 更新 ATLAS + 汇报**，不攒到最后。
- 停止条件：S1 八层做完 + S2 三条做完；或用户叫停。
- 预算意识：每层下载 + 跑 ≈ 1–3 小时机器时间；总 ≈ 15–25 小时。

## 5. 本设计不做的事

不换市场（MT5 / 期货已清点完）；不做日内 / tick；不做龙虎榜追涨 / 题材 / 涨停类短线（V33）；不做 ML1 变体（不同 horizon / 不同 learner 大概率同簇，V27 已证）。
