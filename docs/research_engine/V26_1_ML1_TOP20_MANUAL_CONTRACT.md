# V26.1 合同 — ML1 缩短名单手工执行版（`ML1_TOP20_MANUAL`）

> 2026-09-05 22:30，跑前冻结。起因：用户纠正执行假设——**平安普通账户、小资金、无量化权限、不做非官方 API / computer-use 下单**。执行只能是"系统出短名单，人手下单"。因此可交易的对象不是 V26 的 999 只等权，而是本合同定义的前 N 只。按规则，这是**新合同**（m+1），不是 ML1 的改动；ML1 分数本身一字不动。

## 1. 定义（全部事前固定）

| 项 | 值 | 理由 |
|---|---|---|
| 分数 | ML1 原样（历史 = V25 冻结 2021 模型 `SCORES_ML1_LGBM.npy`；前向 = V29 REFIT_240 live 分数） | 不改模型 |
| N | **20** | 20 笔买 + 20 笔卖 / 20 个交易日，人手可做；再多不现实 |
| 选法 | 合格股票按分数从高到低取前 20（同分按符号序，`lexsort` 同 V14.1） | |
| 权重 | 等权：每只 alloc = 权益 / 20 | |
| 手数 | `lots = floor(alloc / (100 × 次日开盘价))`；`lots = 0` → 该股跳过，顺延下一名，直到凑满 20 或名单耗尽 | 普通账户按手买；价高股买不起 |
| 未成交 | 次日开盘涨停 / 停牌等按 V14.1 `exec_reason` 规则不成交，现金留存，不顺延 | 与所有账本一致 |
| 持有 | 20 个交易日，出场日开盘卖（与 V26 同） | |
| 成本 | `A_SHARE_STRATEGY_COST_MODEL_V1`（佣金 0.025% + 过户费 0.001% + 滑点 0.1%/边 + 印花税卖出）**加最低佣金 ¥5/笔** | 小资金下最低佣金不可忽略 |
| 资金 | 参数，默认 **¥100,000**；只影响手数与最低佣金 | 用户小资金；具体金额用户定 |
| 期链 | 与 V28/V29 相同（信号 t → t+1 开盘进 → t+21 开盘出） | |

## 2. 读取范围

- 历史：研究 2012-01-04→2021-08-24、验证 2021-08-25→2024-02-29，用冻结分数。
- **不读禁用窗 2024-03→2026-08**（`FINAL_OOS_READ.json` 锁对 ML1 派生物同样有效；不用它挑 N）。
- 前向：从 2026-08-28 信号起在 V29 影子账本旁并行记录 `TOP20` 账本。

## 3. 事前预期（写下来防事后合理化）

- 前 20 只 vs 前 20%（~1000 只）：期望收益略高（分数更高），但**方差与回撤显著更大**（个股集中、小盘、涨停不可买的比例更高）。
- 最低佣金在 ¥100k 下每笔 ¥5000，佣金 ¥5 = 0.1%/边，约等于把佣金乘以 4。
- 本合同**不是**为了证明 ML1，而是回答"人手能执行的版本，历史上是否仍是正账本"。

## 4. 门

- 验证期 TOP20 资金收益 > 0，且验证期 TOP20 − 合格 EW > 0。
- 不满足 → `ML1_TOP20_MANUAL_NOT_VIABLE`：ML1 在当前执行条件下**不可执行**，影子账本继续记但不进 Paper；等资金/权限变化再登记新 N（新合同）。
- 满足 → `ML1_TOP20_MANUAL_VIABLE_HISTORICAL`：前向影子账本至少 3 期后，用户可自行决定是否小资金手工 Paper。

## 5. 禁止

跑完不换 N、不改手数规则、不改成本；不看结果后再回到 999 只版本讨论；不读禁用窗；不做任何自动下单。
