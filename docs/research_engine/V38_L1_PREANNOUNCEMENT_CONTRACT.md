## 1. 对象与机制

- **对象**：业绩预告（东财 `RPT_PUBLIC_OP_NEWPREDICT`）+ 业绩快报（`RPT_FCI_PERFORMANCEE`），2008Q1–2023Q4 全部报告期，免费。
- **为什么不是 V16 / V27 的重复**：V16 用年报比率、V27 用正式季报（CPD/BALANCE，`SUE_Q` 来自正式披露的净利润）。预告比正式财报早数周到数月，且带公司自己的增幅区间和预告类型；快报介于两者之间。文献：东方证券 2018（SUE RankIC 4%、IC_IR 3.5、漂移 3–4 个月）、天风 2020 净利润断层（预告触发的 alpha 最强最持久，快报最弱）。
- **机制**：PEAD + 早披露信号 + 公告日跳空（JOR）。

## 2. 数据审计（下载后、建模前，已看）

- FORECAST：每期约 1,600–2,200 只（2019 年报 2,217 只 ≈ 60% 市场）。主行 `PREDICT_FINANCE_CODE=004`（归母净利润）。`IS_LATEST` 全 'T' → 表只留每（股票、期、行）最新版本；**修订后原版本不可得** → 事件在修订公告日才可见，保守、无前视。
- EXPRESS：约 60% 行的 `NOTICE_DATE` 落在期末 390 天后（供应商重标日期 / 上市前回填）→ 用滞后规则剔除。
- 滞后规则：`NOTICE_DATE − REPORT_DATE ∈ [−200, +120]` 天，否则丢弃。
- `NOTICE_DATE > 2024-02-29` 丢弃（禁用窗）。

## 3. PIT 规则

事件自 `NOTICE_DATE` 之后第一个交易日 t1 起可见，持续 ≤120 个交易日，或直到同一股票下一个事件到来（按公告日知识顺序）。无事件的股票特征全 NaN（LightGBM 缺失分支）。

## 4. 特征（9 个，事前写死，不搜）

| 名 | 定义 | 事前方向 |
|---|---|---|
| PA_SURPRISE | 归母净利润同比增幅区间中值 %（缺则由预告金额 / 去年同期算），截断 ±500 | + |
| PA_TYPE | 预告类型序数：预增/扭亏 3；续盈/略增/减亏 1；不确定 0；略减 −1；增亏/续亏 −2；预减/首亏 −3；快报按增幅分档 | + |
| PA_REV | 营收同比 %（预告 006 行或快报 YSTZ） | + |
| PA_NEG_UNCERT | −(上限−下限)/|中值|（区间越窄越高；快报 0） | + |
| PA_LEAD | 期末+120 天 − 公告日（越早披露越大） | + |
| PA_JOR | t1 开盘 / t1−1 收盘 − 1，减去当日合格股票均值 | + |
| PA_CAR3 | t1+2 收盘 / t1−1 收盘 − 1，减均值（t1+2 收盘后才可见） | + |
| PA_ABNVOL | t1 成交额 / 前 20 日均成交额 | 0 |
| PA_NEG_AGE | −(t − t1) | 0 |

PA_TYPE / PA_NEG_AGE 的并列用 `1e-3 × 截断增幅` 打破（`cs_rank_row` 对完全并列按索引排，会注入噪声）。
