## 为什么是这个机制（事前）

V2 证明「07:00 那一根的高低」太矮：下一根常常就打穿，策略退化成盘中永远在场。下一份只把障碍加高，进出时刻仍是 07 / 20，不搜持有、不反向。

## 两份假设（m=2）

共同：一天最多一笔。进 = 信号下一根开盘。出 = 同一自然日第一根 `hour >= 20` 的开盘。缺场或当日出不了 → 空仓。成本 = 点差 + 2×2bp，隔夜=0。覆盖率 = 成交日 / 有 07:00 且能出场的日。闸门同 V2。

1. **PREV_DAY_HL**  
   障碍 = 上一个有 bar 的自然日的最高 / 最低（全天，不只用 07:00）。当日 07–19 第一次收盘打穿则跟方向。

2. **LONDON_ORB_ATR05**  
   障碍 = 07:00 高 + `0.5×ATR14`、低 − `0.5×ATR14`。ATR14 只用该根及以前。0.5 是半根近期波动，不是从 V2 覆盖率反推的 λ。其后扫到 19 时第一次收盘打穿。
