## 2. 这说明什么

"事先判断谁近期会涨停"**做得到**：近期振幅大（`EVT_AMP_5` 增益 25%）、近 10 日已经涨停过（`EVT_NLU_10` 10%）、高波动（`NEG_VOL_60` 12%，方向为高波动）的股票，未来 5 天涨停概率是别人的 3 倍。

但同一批股票的**5 日平均收益是深度负的**。原因不是外壳（¥1M 的大账本同样 −66%）、不是成交（成交率 80% 以上）、不是成本单独造成（毛收益本身为负）。原因是彩票效应：涨停概率高 = 振幅大 = 跌停概率同样高，偶尔 +10% 的尾部被更多的 −5%…−10% 淹没。这与 ML1 里"低波动股票长期跑赢"是同一枚硬币的两面——ML1 做多的正是这个模型不选的股票。学术上叫 MAX / lottery-stock 效应，A 股上尤其强。

## 3. 对用户问题的回答

- "策略是不是暂时不适合小资金" —— V33 用你描述的方式（前几日异动 + 基本面 + 技术面，事先预测）做了一个完整的小资金版本。**能预测，不能赚钱**，而且大资金版本同样不能赚钱。所以不是资金规模的问题。
- 消息面 / 政策面没有进特征（免费源没有），这是真实缺口。但它们改变的是命中率，而命中率已经是 3 倍基础率了，问题在于"命中之后的平均收益为负"，多命中一些改不了符号。
- 短线 / 快进快出：持有 5 日的成本频率是 20 日的 4 倍，这里已经体现。再高频 = 成本再翻倍。

## 4. 禁止

不调阈值、持有期、特征；不做日内 / 分钟变体；不因 G1 极强而为 V33 找"能赚钱的账本"（那就是用结果挑账本）；不把 `SCORES_ML3_LU5` 反向当作"回避名单"塞进 ML1（那是改 ML1 特征 = 新合同，且 NEG_VOL 已经承载了同一信息）。
