## 网格（13 条，事前固定）

对每只持仓，从买入日起每日**收盘价**判定，触发则**次日开盘**卖（遇跌停/停牌按 V26.4 顺延）。未触发按原计划到期卖。提前卖出的现金闲置到下一个信号日（保持信号节奏，和手工执行一致）。

| 组 | 规则 |
|---|---|
| BASE | 无（= 现状） |
| 止盈 TP | 收盘 ≥ 买入价 × (1+x)，x ∈ {5%, 10%, 20%} |
| 硬止损 HS | 收盘 ≤ 买入价 × (1−s)，s ∈ {5%, 10%} |
| 移动止盈 TRAIL | 收盘 ≤ 持仓期最高收盘 × (1−y)，y ∈ {5%, 10%} |
| 保本止损 BE | 收盘曾 ≥ 买入价 × (1+z) 后，收盘 ≤ 买入价即卖，z ∈ {3%, 5%} |
| 组合 | TP10 + TRAIL10；BE5 + TRAIL10 |

## 事前预期

- 日线止损/止盈 = 次日开盘成交，吃跳空；A 股股票日波动大，5–10% 的止损在 20 日窗口内被频繁打到，属"高位止损、低位卖出"的追涨杀跌形态。已有文献与 V14.1 时代的经验：固定止损对截面选股账本通常是负贡献；止盈截断右尾。
- V33 若靴子在左尾，硬止损/移动止盈可能把 −88% 变得不那么惨，但不会翻正：毛期望为负的分布不能靠出场规则造出正期望（出场规则不能改变买入后的价格路径分布，只能截断）。
