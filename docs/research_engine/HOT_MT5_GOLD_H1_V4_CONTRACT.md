## 为什么是这个机制（事前）

V1 路径：24 小时里平均先走过 +83 bp 再吐回。V2 跟随 1 小时突破毛利为负——小区间第一下常是扫止损。教科书对应的是「亚洲区间、伦敦假突破反向」，障碍是 **00–06 UTC 箱体**，不是 07:00 那一根，方向是反向不是跟随。进出时刻仍锁 07 扫描 / 20 出场，不搜。

## 一份假设（m=1）

**ASIA_FADE**

- 箱体 = 该日 `hour ∈ [0, 6]` 的最高 / 最低。该区间一根都没有 → 当日空仓。
- 从该日 `hour == 7` 扫到 `hour == 19`：第一次收盘 > 亚洲高 → **空**；< 亚洲低 → **多**。一天最多一笔。
- 进 = 下一根开盘。出 = 同一自然日第一根 `hour >= 20` 的开盘。出不了 → 空仓，不隔夜。
- 成本 = 点差 + 2×2bp。覆盖率 = 成交日 / 有 07:00 且能出场的日。闸门同 V2。
