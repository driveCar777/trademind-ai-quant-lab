## 为什么是这个机制（事前）

法医三句，不是调参：

1. 十四列特征和 120 小时动量对未来 24 小时收益 |IC| < 0.07；再训一棵 24 小时符号树 = 同一口井。
2. 神谕「只做 \|毛\| > 2×成本」方向仍亏 → 再加空仓门槛救不了 V1。
3. 持有期内平均 MFE +83 bp、89% 大于 2×成本，买持有 +250% → 波动在**当日路径**，不在 24 小时收盘符号。

因此本份 = 无树、当日进当日出、允许空仓。不是搜 8/12/36 小时。不是日线 V4 的小时版。

## 两份假设（m=2）

共同：一天最多一笔。进 = 信号下一根开盘。出 = **同一自然日**第一根 `hour >= 20` 的开盘。没有 07:00 UTC 的日、或进场后当天没有 ≥20:00 的 bar → 该日空仓（不隔夜、不拿周末）。

成本 = 当根点差 + 2×2bp。隔夜利息 = 0（同一自然日）。

1. **LONDON_ORB**  
   区间 = 该日唯一一根 `hour == 7` 的高/低。缺这根就空。从其后第一根扫到 `hour == 19`：第一次收盘 > 区间高 → 多；< 区间低 → 空。

2. **DONCHIAN24_SESSION**  
   从该日 `hour == 7` 扫到 `hour == 19`：第一次收盘 > 此前 24 根最高 → 多；< 此前 24 根最低 → 空。当前 bar 不计入通道。

## 闸门

主报告 = 全样本。验证 = 有 07:00 的日后 30%（按日切，不是按小时切）。  
覆盖率 = 验证成交日 / 验证期有 07:00 的日。  
验证成交 < 8 或覆盖 < 15% → `NO_CANDIDATE`。  
否则验证 TWR > 0 且 t > 1 → `VIABLE_HISTORICAL`。`candidate` 仍 false。  
最近一个月只诊断。
