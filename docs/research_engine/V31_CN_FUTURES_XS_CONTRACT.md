## 0. 跑前修订（分数尚未生成）

设计稿写「首预测 2008、研究 2008→2019」。拉取完成后确认：**诚实的 20 日收益只能从逐合约来**（连续序列在换月日有价格跳变，用它做账本 = 期货回测最常见的错）。逐合约多数从 2018-05 起。因此：

- 特征里的动量/波动/持仓仍用主力连续（≤ t 结算，连续跳变对 60/250 日特征的影响事先接受）。
- **标签与账本收益 = 信号日主力合约持有 20 日的同合约开盘→开盘**，不用连续价差。
- 首预测、研究/验证划分改为 2019-07 起（合约史 + 250 日合格 + 约 1 年训练标签）。修订发生在任何分数之前，不构成事后选择。

## 1. 宇宙

- 品种 = 设计稿预声明 73 个（SHFE/INE/DCE/CZCE/CFFEX/GFEX），新浪未返回的记缺失，**不按结果删品种**。
- 时间轴 = 全体连续序列交易日并集。
- 信号日 t 的主力合约 = 该品种当日持仓量最大、且 `volume > 0`、且该合约在 t+1 与 t+1+20 都有开盘价的合约；若无满足「活到出场」的，取持仓最大且 t+1 有开盘者，出场用该合约最后一根有效开盘（记 `EARLY_EXIT`）。

## 2. 合格（每日 t）

主力连续有效收盘；连续史 ≥ 250 日；20 日均持仓 ≥ 当日全品种 20 日均持仓的 20 分位；非上市首年（连续首根起 < 252 日剔除）；信号日能确定主力合约且 t+1 可开仓。截面少于 15 只当日不交易。

## 3. 特征（8 个，事前固定，全部 ≤ t）

| 名 | 层 | 定义 |
|---|---|---|
| `XS_MOM_60_20` | 连续价 | 60 日收益 − 近 20 日收益 |
| `REV_20` | 连续价 | −20 日收益 |
| `NEG_VOL_60` | 连续价 | −日收益 60 日标准差 |
| `OI_CHG_20` | 连续持仓 | 20 日持仓变化率 `(OI_t / OI_{t-20} − 1)` |
| `VOLU_RATIO_20_120` | 连续量 | 20 日均量 / 120 日均量 |
| `NEG_LOG_AMT_20` | 连续 | −log(20 日均 成交量×收盘) |
| `TERM_SLOPE` | 逐合约 | `(次月结算 / 主力结算 − 1) / 年化月差`；无次月则 NaN |
| `BASIS_MOM_20` | 逐合约 | `TERM_SLOPE_t − TERM_SLOPE_{t-20}` |

进模型前做横截面排名（同 V25 `ranked_row`）。LightGBM 原生吃 NaN（2019 前期限结构大量 NaN，2019 后仍可能缺）。

## 4. 模型（A3，一个）

- LightGBM 回归，参数 = V25 `LGBM_PARAMS` 逐字。
- 目标 = 20 日同合约开盘→开盘收益的截面排名（减 0.5）。
- 训练行：2018-06-01 起每 5 日、标签在 refit 日之前完全可知（embargo = 21）。
- Walk-forward：首预测 **2019-07-01**，研究期内每 **240** 个交易日 refit，expanding；**2023-06-30 后冻结**（验证期用冻结模型）。
- 分数矩阵 `SCORES_V31.npy`。

## 5. 账本与成本

- 信号 t 收盘 → t+1 开盘进 → t+1+20 开盘出；等权；不成交记 0（现金）。
- **闸门账本 LS 三分位**：多前 1/3、空后 1/3，各 100% 名义（美元/人民币中性，总敞口 2×）。截面小，三分位事前定，不用五分位。
- 诊断账本 LO 前 1/3（多头 only）。
- 成本（保守、事前固定，不按品种事后调）：每边 **手续费 1.5 bp × 1.2 券商加收 + 滑点 1.5 bp = 3.3 bp**；往返 6.6 bp/腿。无融资费。保证金占用不记无风险利息。
- 基准：当日合格品种等权 20 日前向（EW，同合约算法、不含成本）。
