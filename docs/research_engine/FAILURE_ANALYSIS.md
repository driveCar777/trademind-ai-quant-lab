# FAILURE_ANALYSIS

> 2026-09-13。MT5 路径取证。目标不是把收益率做高，是回答：**为什么长期无法稳定盈利，哪些结果是假的。**  
> 配套：`STRATEGY_FORENSIC_REPORT.md`。不改核心代码、不重训。

## 0. 总判（先读这个）

无法稳定盈利，**主因不是少了一个保本损**，而是：

1. **能发单的逻辑没有边。** `:9001` 热台是 Grok 叙事交易。无预注册、无 OOS、无止损。研究分数不进提示词。  
2. **量过的价内 ML 没有边。** D1 V1 黄金 −18%；H1 树过拟合（训练 IC 0.52 / 折外 0.038），净 −35%～−67%。  
3. **唯一过历史闸门的 V4 不是独立 alpha。** 验证 +84% 吃的是 2024–26 金牛；研究 −10%；空头 −27%；弱于买持有 +250%。`candidate=false`。  
4. **标签不是「赚钱」。** 模型拟合 **未扣成本的开盘到开盘收益符号**；账本永远在场，点差+滑点+隔夜把均值吃掉。  
5. **执行 ≠ 回测。** 研究是下一根 D1/H1 开盘 + 固定持有。Demo 是即时市价、M15 直觉、无时间止。即使 V4 有边，Grok 也没在交易它。  
6. **回测数字本身大体不是算错。** H1 1752 笔对账 0 错位。差的是假设，不是加减法反了。

本机 `MT5_JOURNAL.json` 不存在：仓库 **算不出** Ava demo 账户的权益曲线。终端亏钱若存在，对不上任何一份 `READ.json`。

## A. Data Problems

| 检查项 | 判定 | 证据 |
|--------|------|------|
| 来源 | Ava 终端 `copy_rates_from_pos` + 必要时冻结宏观包预置 D1 | `hot_mt5_products/pull.py` |
| 时区 | K 线写成 UTC | `fromtimestamp(..., tz=timezone.utc)` |
| 会话钟 | 热台 08:30/20:30 用 **`datetime.now()` 本地时** | 与 UTC K 线不是同一钟 |
| Bid/Ask vs OHLC | 研究用 bar OHLC + `spread` 列；热台用 tick bid/ask | 两套价 |
| Spread | 历史 `spread` 点；缺失则用 **当前** `spread_points_now` | 轻微用「现在的点差」垫历史成本 |
| 缺失/重复 | merge 按 `timestamp_utc[:19]` 去重；Ava 一次拉 10 万根常空，改步进 8k→8万 | 不保证周末/假日完整，黄金 D1 含额外场次 |
| 符号 | 逻辑 `XAUUSD` ↔ 经纪商 **`GOLD`** | 映射正确。不是 XAUUSD 不存在就没数据 |
| Tick/bar | 无 tick 农场。热台只塞 20 根 M15 close | 研究 H1/D1 ≠ 执行 M15 |
| OHLC 用法 | 信号用 close[t]；成交用 open[t+1] | 正确、无用未来收盘成交 |
| 冻结预置 | live D1 与冻结包按时间戳合并 | 可能混两个下载世代，但键是时间戳不是「未来」 |

**Data Leakage（特征用未来价）？ `FALSE`（研究主路径）。**  
信号 t 的特征来自 close[t] 及更早；进场 open[t+1]。H1 对账 0 错位。

**Data Leakage（成本/门槛用了「现在」）？ `PARTIAL`。**  
`_spread_pct`：`max(历史点差, 0.25×当前META点差)`。V2 标签门槛用 **当前** META 预期成本，不是当年点差。这会让历史「该不该做」略向今天的费率弯曲，**不是**价格未来函数。

**热台快照：** 20 根 M15 是当前终端，无未来。Grok 联网宏观 **不是** 价格泄漏，是无验证的外生叙事。

## B. Label Problems

D1 V1 / H1 V1 定义（`engine.py`）：

```text
y[t] = open[t + 1 + hold] / open[t + 1] − 1
```

| 项 | 事实 |
|----|------|
| Horizon | D1：GOLD 10，FX/油 5；V4：20。H1：24 小时 |
| 重叠样本 | **每个 t 都有标签**，相邻 y 共享 hold−1 根。训练样本严重重叠。账本成交 **非重叠** |
| 成本进标签？ | V1/V4/H1 回归：**否**（只在 book 里减） |
| V2 | 标签 = 毛 y 是否超过 `2×` 预期往返成本，否则 CASH |
| 类别不平衡 | V2 本想 CASH 为主，实测 CASH 4–20%；V3 反过来 CASH 79–88% |
| 中性类 | V1 `sign` 把 score=0 当空，**没有中性** |
| Label leakage | y 用未来开盘，特征不用未来开盘。**不是**把成交价写进 X |
| clip | 训练 `np.clip(y, -5, 5)` 防原油式极端，不是泄漏 |

**模型预测的目标 ≠ 最终赚钱的目标。**

- 拟合：下一段 **毛** 开盘收益（或它是否大过一个过矮/过高的门槛）。  
- 交易：永远（或几乎永远）在场，再扣点差 + 2×2bp 滑点 + 隔夜。  
- 黄金 H1：毛 +80%，净 **−35%**。边若存在，也小于成本。  
- 热台 Grok：**没有标签。** 它不优化任何 y。

重叠标签让训练 IC 好看、折外崩，与 H1 真样本内 0.52 / 折外 0.038 同构。

## C. Feature Problems

**D1 V1（GOLD 13 列）**  
`R1 R5 R20 VOL20 VOL60 ATR14 DIST_SMA50 DIST_SMA200 RSI14 GAP RANGE_ATR DOW MONTH`  
全是 **自己的 OHLC**。无成交量真值依赖（用波动替代）、无新闻、无跨品种（USDCAD 不加原油）。

**H1 V1**  
同上 + `HOUR`。`DIST_SMA200` 在小时线上是 **200 根小时 ≈ 8.3 日**，不是 200 日趋势。这是 **错误尺度**，不是未来函数。

**H1 V5**  
`R1/R6/R24 VOL24/120 ATR14 DIST_SMA24/120 RSI14 RANGE_ATR HOUR_SIN/COS DOW`

**H1 V9**  
先验 5 列：`R24 VOL24 DIST_SMA24 HOUR_SIN HOUR_COS`。少列救不回折外 IC。

| 风险 | 判定 |
|------|------|
| 冗余 / 高相关 | R1/R5/R20、双波动、双均线距离：预期共线。树能吞，线性 V6 训练 IC 只有 0.055 |
| 不稳定 | MONTH/HOUR 在牛市切片上可被记成日历记忆 → 过拟合通道 |
| 未来特征 | **未发现**（GAP 用当日开盘/昨收，收盘时已知） |
| Scaling leakage | LGBM 无全样本 scaler。V6 折内 z-score |
| 推理时不可得 | 研究推理用同一 CSV。热台 **不用这些特征** |

V4 **零特征**：只要 `close[t]/close[t-252]-1` 的符号。

## D. Train / Validation / Test / Paper

```text
Ava D1/H1 CSV  (+ D1 可合并冻结包)
        |
特征 X[t]  ← close[t] 及过去
标签 y[t]  ← 未来开盘收益（重叠）
        |
Walk-forward
  fit  on rows < t − embargo
  pred on [t, t+REFIT)
  每个分数对「该 t」是 OOS
        |
非重叠账本 book(sign, next open, hold)
        |
        +-- research_70 : FIRST_PRED 之后前 70% 根  → 报告
        +-- validation_30: 最后 30% 根              → 闸门
        |
没有独立 TEST
没有把该账本接到 PAPER/DEMO
        |
PAPER/DEMO (另一条线)
  Grok × 2/工作日 + 市价
  与上面分数无关
        |
FOLLOW
  只展示 V4 日线状态
```

| 问题 | 判定 |
|------|------|
| Walk-forward 分数是不是 OOS？ | **是。** embargo = hold+1 |
| `research_70` 是不是样本内？ | **不是。** 曾被误读；H1 已用真训练集 IC 纠正 |
| `validation_30` 有没有被用来选家族？ | **是（选择泄漏，不是 Hot-label）。** 闸门：验证 TWR>0 且 t>1 → `VIABLE_HISTORICAL`。V4 黄金因此入围跟盘叙事。参数 252/20 **跑前写死**，但 **选哪本账给人看** 看过验证窗 |
| 禁用窗 2024-03→2026-08 | A 股规则。MT5 热台 **没有** 同等冻结；验证窗正好盖住金牛 |
| Paper | 热台 demo ≠ 研究 paper。无 `MT5_JOURNAL` 则连纸面成交都没有 |
| 超参搜索 | 代码内 **无** grid。V1→V9 是研究者序列，每份号称一次，但家族个数本身是 m |
| 自动优化 | 无 Sharpe 最大化循环。只有定期 refit |

**回测幻觉类型（本仓库实际有的）：**

- **永远在场幻觉：** 目录写 TREND，数学是 coin-flip + 成本。  
- **验证窗幻觉：** V4/V5/H1 V3 昨日高低只在 2024–26 好看。  
- **样本内幻觉（已纠正）：** 把 WF 研究窗当成「没拟合」。  
- **执行幻觉：** 以为跟盘/Grok 在交易过门账本。  
- **上帝视角出场（诊断，未上线）：** 用 MFE 当收益 → 幻想 +4154%。已标记 `DIAGNOSTIC_NOT_A_BOOK`。

## F. 执行 / 成本 / 滑点

| | 研究 book | 热台 demo |
|--|-----------|-----------|
| 成交价 | 下一根 **open** | 当时 **ask/bid** |
| 点差 | 历史 spread 与当前 META 的 max 规则 | 真实 tick |

## G. 风控

代码里的「风控」是 **权限闸**，不是价格风险：

- live 账户拒绝  
- 股票篮子不发  
- 每品种 1 笔、不叠仓  
- 每天最多 2 次 Grok  

**没有** 账户最大回撤、单笔风险%、保证金占用上限、波动熔断、会话强平。  
当前设置手数 **0.1**，GOLD 合约 100，点值大。这是操作风险，不是研究边。

V34 / V4 路径诊断：紧止损在趋势账上会砍掉赢家。缺止损 ≠ 加上去就会盈利。

## H. 绩效计算

研究：非重叠净收益连乘 → TWR / CAGR / t / MaxDD / hit / payoff。  
CAGR 用 `n_trades × hold / 252` 或日历年，两套混用时不要横比。

热台：`positions().profit` 可从终端读浮动盈亏；**仓库没有** 权益曲线、没有按日盯市账。  
`view()["orders_sent"]` **写死 False**，即使 demo 已经 `order_send` 成功，页面状态也不承认发过单。  
`gold_follow` 盯市是进场开盘 vs 最后收盘，不是账户货币。

GOLD D1 实测：2411 根、时间戳单调、**0 重复**；`spread=0` 的 2 行走 META 当前点差回退。`READ.json` 存在则拒绝重训：CSV 再拉长、分数不重算，是运营陈旧，不是价格泄漏。

## L. 设计错误（按杀伤力）

1. **把「观察台 LLM」和「研究账本」做成同一产品。** 用户看到亏钱，会去调已经证伪的树。  
2. **`sign(score)` 永远在场** 当作可交易策略。问句是方向，成本结构要求「经常空仓」。V2 想休息，门槛写错。  
3. **标签不含成本，闸门却用成本后 TWR。** 模型不优化它被考核的东西。  
4. **重叠标签 + 深树** → 记噪声。Ridge/稀疏列已证明不是「还没记住关键特征」。  
5. **H1 复用 D1 列名**（SMA200）。  
6. **用最后 30% 金牛当「过门」** 然后做跟盘叙事。  
7. **执行无止损也无时间止**，与任何量过的外壳都不同。  
8. **手数设置已到 0.1**，风控仍是「demo 才能发」。  
9. **不写成交 journal**，系统不可审计。  
10. **平仓手数 ≠ 持仓手数**；发单 magic 与热台常量不一致；`orders_sent` 永远假。页面不能当成交真相。
