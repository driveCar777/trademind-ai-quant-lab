## 汇总
- 🟢 已实现（A-Short）：**0 个信息需求**（只有 20D 动量 + 引擎）。
- 🟡 有代码未接入：宏观/海外/汇率/商品/北向(市场级)/财务/行业/指数/ML/LLM/纸面（约 11 类）。
- 🔴 完全无代码：热点/下一波热点/龙头/政策文本/美联储/个股资金流/龙虎榜/一般公告文本/分钟。

## 结论
需求覆盖面 = 一个完整**短线热点交易研究系统**；当前落地 = **20D 动量 + 引擎**。缺口以"数据 + 信息层接入 + 热点/龙头衍生"为主，且被 **D1 冻结字节在 Cloud 不可用**硬阻塞在最底层（Phase 4）。任何新数据/信息层须新预注册合同，不采购、不换源、不改 hash（当前禁）。
