> 真实交易成本重审（§14）。**逐笔按订单 notional 计**，不用一个固定「≈0.27%」代替。
> 常量来源（不臆造）：`research_engine/cn_a_share_alpha/cost.py` + `cn_a_share_ml_v25/top_n_book.py::_fee`。

## 1. 成本构件（逐项，来自代码）

| 构件 | 值 | 侧 | 出处 |
|------|----|----|------|
| 佣金 commission | `0.00025`（0.025%），**最低 ¥5** | 买+卖 | `cost.py::COMMISSION`；`top_n_book::MIN_FEE=5.0`（仅佣金有最低） |
| 过户费 transfer | `0.00001`（0.001%） | 买+卖 | `cost.py::TRANSFER` |
| 印花税 stamp | `0.0005`（0.05%，2023-08-28 起；之前 0.0010） | **仅卖** | `cost.py::STAMP_NEW`/`stamp_duty_sell` |
| 滑点 slippage | `0.0010`（0.1%）/侧（**建模假设**，可校准） | 买+卖 | `cost.py::SLIPPAGE` |
| 一手 | 100 股 | — | `top_n_book::LOT=100` |

逐笔公式（per-name notional = P）：
```
buy_fee  = max(5, P*0.00025) + P*0.00001
sell_fee = max(5, P*0.00025) + P*0.00001 + P*0.0005
round_trip(¥) = buy_fee + sell_fee + slippage_side*2*P
round_trip(%) = round_trip(¥) / P
```
> **口径统一**：以后所有文档引用成本，一律指「按 P 逐笔算出的 round_trip(%)」，并注明是否含滑点。不再用单一「0.27%」。

## 2. 往返成本 vs 每股名义金额（核心表）

| per-name 名义 P | 仅费用 RT% | 含滑点(0.1%/侧) RT% | 备注 |
|---|---|---|---|
| ¥2,000 | **0.552%** | **0.752%** | ¥5 最低佣金主导（买卖各 0.25%） |
| ¥5,000 | 0.252% | 0.452% | 最低佣金仍绑定 |
| ¥10,000 | 0.152% | 0.352% | |
| ¥20,000 | 0.102% | 0.302% | 佣金临界点：P≥¥20,000 后最低佣金不再绑定 |
| ¥50,000 | 0.102% | 0.302% | |
| ¥100,000 | 0.102% | 0.302% | 渐近下限 |

**关键结论**：
- **¥20,000/名 是佣金临界点**（`P*0.00025 = 5`）。低于它，¥5 最低佣金把成本抬到 0.25%–0.55%（仅费用）。
- 小账户被迫落在**最差成本带**：仓库默认 `UNIT_YUAN=¥2,000`/名 → RT ≈ 0.55%（费用）/ 0.75%（含滑点）。

## 3. 账户规模 → 可行每名名义 → 成本带

假设等权、每名≥1 手、参考单位 ¥2,000（可调）：

| 账户 | 典型可持名数 N | 每名名义 P | RT%(费用) | RT%(含滑点) | 成本带 |
|---|---|---|---|---|---|
| ¥2,000 | 1 | ¥2,000 | 0.552% | 0.752% | **最差** |
| ¥5,000 | 1–2 | ¥2,500–5,000 | 0.45–0.25% | 0.65–0.45% | 差 |
| ¥20,000 | 3–10 | ¥2,000–6,700 | 0.55–0.20% | 0.75–0.40% | 差（受 N 影响） |
| ¥100,000 | 10–20 | ¥5,000–10,000 | 0.25–0.15% | 0.45–0.35% | 中 |
| ¥1,000,000 | 20–50 | ¥20,000–50,000 | 0.102% | 0.302% | 最好（仍受滑点主导） |

> 账户越小、单名越小 → 成本越高。这正是 owner 小资金场景的结构性劣势（V26 系列反复记录：**缺口是本金不是边**）。

## 5. 最终回答（§14、§28.Cost）：需要多少 gross alpha 才能净正？

**净正条件（每笔）**：`per-trade gross return > round_trip(%)`。

**每笔毛收益下限（breakeven，net=0）**：

| per-name P | 含滑点每笔需 > | 仅费用每笔需 > |
|---|---|---|
| ¥2,000 | **0.75%/笔** | 0.55%/笔 |
| ¥20,000+ | **0.30%/笔** | 0.10%/笔 |

**要净赚 +X%/年**（近似 `per-trade gross ≈ RT% + X% * hold/242`）：

- **T+1，大账户(P≥20k)，含滑点**：每笔需 > 0.30%，且年化 73% 摩擦 → 要净 +10%/年需毛 ≈ 0.34%/笔且胜率极高 → **实务上不可行**（与 `MT5_STOCK_CFD_COST_CEILING` 同型）。
- **T+1，小账户(¥2k)**：年化 133–182% 摩擦 → **判死**，不建 T+1 模型于小账户。
- **T+3，大账户含滑点**：每笔需 > 0.30%，年化 24% 摩擦 → 净 +10% 需毛 ≈ 0.42%/笔 → **偏难但非不可能**。
- **T+5，大账户含滑点**：每笔需 > 0.30%，年化 14.6% 摩擦 → 净 +10% 需毛 ≈ 0.50%/笔 → **最有希望的短周期带**。
- **T+5，小账户(¥2k)**：年化 36% 摩擦 → 需毛 ≈ 0.75%/笔 → 很难。

## 6. 决策结论（写入基线）

1. **成本天花板先于模型。** Phase 2 第一步 = 用本表 + `cost.py` 逐笔重算，**过不了 breakeven 下限就不建模**。
2. **优先 T+5、其次 T+3；T+1 仅在大账户 + 极高毛 alpha 下研究，小账户 T+1 直接放弃。**
3. **小账户结构性劣势明确**：¥2k–¥20k 落在最差成本带，缺口是本金；不为凑收益改 hold/成本/仓位（沿用 V26 纪律）。
4. **滑点待实测**：默认 0.1%/侧是保守假设；Track A 研究时应用成交量/流动性校准滑点，但在实测前用默认值筛（宁可保守）。
