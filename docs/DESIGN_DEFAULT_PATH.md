# 控制台默认计算路径

> **状态：** 已落地 2026-08-23。Smoke 07 PASS。SPEC §8.4 + Decision 019。  
> **不是 V4。** 不自动选策略、不自动问 AI。

## 要解决什么

打开控制台仍要选四种类型；点记录后 AI 只能看到任务请求，看不到 RSI / 评分 / 回测数字。

## 原则

| 维度 | 做法 |
|------|------|
| 易用 | 顶栏推荐一笔在线计算；点一次即可 |
| 鲁棒 | 离线类型不提交；结果文件坏了详情仍 200 |
| 性能 | 列表不读结果；不自动推理；不每次刷新自动算 |
| 简洁 | 不新造错误码；不新 Worker；不改计算接口 |

## 不做

- 打开页面自动 `POST /task`
- 算完自动问通义千问
- 网页重启 AI Gateway
- V4 研究代理
