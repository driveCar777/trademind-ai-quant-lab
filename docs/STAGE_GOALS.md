## 最终目标

在你自己的机器上跑通这一条，并且**每天能用**：

```
数据 → 指标计算 → 因子分析 → 策略回测 → AI 分析 → 交易辅助
```

**完成时应当是：**

1. 四台 Xavier 继续只负责计算（指标 / 因子 / 回测 / 监控）。  
2. Windows 只负责调度、控制台、通义千问。  
3. 人可以让系统**替自己跑完一轮研究**（算 + 读 + 留下报告），而不必每一步手点。  
4. 研究结论能接到 MT5，先**模拟**，再谈实盘。  
5. 仍然是个人实验室，不是券商，不是无人值守实盘。

**「交易辅助」未拍板的部分：** 下单前要不要人手确认。V5 设计时再定，现在不当成已决定。

**现在还没到最终目标。** 现在停在：人能算、人能问 AI。V4 设计已写，未实现。V5 未开始。

## 后面怎么走（三个模块，每个五步）

规则不变：一次只做一个模块；一步没过，不准开下一步；没冻结，不准开下一个模块。

每一步的**通用目标**先记在这里，下面按模块写成可验收的句子。

| 步 | 名称 | 这一步结束时必须达到 |
|----|------|----------------------|
| 1 | Design | 做/不做、接口、失败怎么停都写死。你点头之前不写该模块业务代码。 |
| 2 | Implement | 只按已生效 SPEC 实现。不顺手做下一模块。 |
| 3 | Smoke | 最核心路径实测通过。失败则停，修完再测。 |
| 4 | Stability | 重复跑、超时、失败形态可预期。不靠「偶尔能过」。 |
| 5 | Freeze | 文档与代码一致。冻结后才允许开下一模块。 |

### 模块 A — V4.0 Research Agent（下一刀）

**本模块目标：** 人点一次「研究一笔」，系统用**现有**计算 + **现有** AI 跑完一轮，并存档。  
**本模块达不到最终目标**（没有自动选股、没有 MT5）。

| 步 | 状态 | 这一步的目标（做到什么才算过） |
|----|------|--------------------------------|
| 1 Design | ✅ 已写 | 范围锁死：1 次 `POST /task` + 至多 1 次 AI；人手点；无队列/库/MT5。产出：`DESIGN_V4_RESEARCH_AGENT.md` + SPEC §16 草案。 |
| 2 Implement | ✅ | SPEC §16 生效：`POST/GET /api/v1/research*`、`data/research/`、控制台「研究一笔」。不改 Worker。 |
| 3 Smoke | ✅ PASS | 01 在线时跑通 indicator：有 `task_id`、摘要含 RSI；网关忙则 `ai_skipped` 仍成功；非法 preset → TM-1001；进行中再跑 → TM-1005；页面 `init` 不自动研究。 |
| 4 Stability | ✅ PASS | 连续 10 次「研究一笔」不崩调度中心、不双开 14B；Worker 离线 / 网关 503 都有稳定错误或 `ai_skipped`。 |
| 5 Freeze | ✅ 2026-08-23 | CHANGELOG / TODO / CONTEXT / SPEC §16 与行为一致。 |

V4.0 已冻结。下一模块见下方模块 B。
