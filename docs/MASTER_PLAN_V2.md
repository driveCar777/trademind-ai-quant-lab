## 一、对原设计的诚实审查

先说做对的：**研究纪律**（预注册、成本模型、非重叠账本、FDR、失败图谱、不改历史）是这个项目最有价值的资产。它让 30 多个家族的失败都有记录、不重复，也让唯一的成功（ML1）经得起复现和真样本外。这部分一个字不改。

再说走偏的（不是批评，是你不懂所以按"软件项目"的直觉设计了，很正常）：

| 原设计 | 问题 | 修改 |
|---|---|---|
| 四台 Jetson Xavier 分布式集群 + Docker + Master/Worker 调度 | 量化研究的瓶颈是**数据与统计**，不是算力。ML1 全量拟合 245 万行只要 33 秒，在 Windows 单机上。Xavier（Python 3.6、无 pip）反而限制了能用的库。 | **冻结、不再投入。** 研究全部在 Windows 跑。集群不拆，但不再是路线图的一部分。 |
| AI Gateway（本地 Qwen 14B 写投研报告 / 解读信号） | LLM 不产生 alpha；"信号解读"是把噪声写成文章。花掉的时间没有换来任何一条正账本。 | **冻结。** 以后若用 LLM，只做文档整理，不进研究链。 |
| Backtest Worker 的 7 个策略（EMA/MACD、RSI、海龟、网格、布林、VWAP……） | 教科书策略，全部没有样本外证据；V11 在 MT5 上已经证伪。 | **不再维护。** 任何新策略必须是"合同→跑→决策"产出的 Candidate，不是预置菜单。 |
| 「谨慎」体现在人手确认纸质单、模拟单、多层 Phase 报告 | 这是**错位的谨慎**：对没有边的 RSI 信号，人手点确认不会让它变有边；而对真正需要谨慎的地方（多重检验、样本外、成本）原设计反而没有约束（V1–V9 时期）。 | 谨慎放在**统计门**上（已做）。执行侧的"人手确认"保留但只对有 Candidate 的策略有意义。 |
| 目标写成"V5.0 MT5 实盘交易链路" | 载体先于策略。MT5 这家经纪商的产品清点结果：宏观 CFD 只有约 70 个品种（无截面）、股票 CFD 多头融资 11%/年。它不适合作为**主**载体。 | MT5 降为"可选执行口"，不是研究对象。 |

一句话：**原规划把 80% 精力放在平台，20% 放在研究；有证据的价值 100% 来自研究。倒过来。**

## 二、逐市场判决（基于已有证据 + 实测费率）

### 1. A 股 —— 唯一有证据的市场，优先级 1

- 证据：ML1 三段互不重叠正账本（+276% / +30.9% / +71.4%），Final OOS 通过，全程 CAGR ≈ 13.7%，其中一半以上是小盘 β。V29 管线已能每日出名单。
- 要做的：
  1. V29 稳定性（周一起 5 个交易日 + 09-29 第一期结算）→ 冻结。
  2. **执行假设（2026-09-05 22:20 用户纠正，为准）**：用户是**小资金、平安普通账户、无量化权限、短期开不了**。因此：**不把 QMT/PTrade、999 只等权自动下单当 ML1 的实盘路径**；不做 computer-use / 非官方 API 下单。执行只有一种形态：**系统出短名单（前 N 只 + 每只金额上限），用户自己在普通账户手工下单**。这就是合同 `V26_1_ML1_TOP20_MANUAL`（N=20、等权、按手取整、最低佣金 ¥5、板块按用户权限过滤）。历史读取（不含禁用窗）：全板 / 主板+创业板 / 仅主板三种权限口径的验证期资金收益均为正且打过 EW——**板块由用户权限决定，不由结果挑**。QMT 等以后资金和权限到位再谈，那时是新合同。
  3. Paper：V29 每天同时出 999 只参考名单（V26 账本）和 20 只手工短名单（V26.1）；影子账本两条并行。用户自行决定何时开始用短名单手工 Paper / 小资金。
- 不做的：为 10% 改 ML1；把 HN20 当策略；重开 V13–V24 家族。

### 2. 中国大陆期货 —— 没研究过、条件最好的新对象，优先级 2

为什么它是下一刀（而不是美股或 MT5）：
- **有截面**：上期所/大商所/郑商所/中金所约 60–70 个活跃品种，加上每个品种的多张合约 → 期限结构可算。这是 MT5 宏观 CFD（~15 个商品、无期限结构）完全没有的信息。
- **成本低**：无融资费，手续费万分之 0.5–几，点差一两跳。20 日往返成本 ≈ 0.05–0.15%，是股票 CFD 的 1/15。
- **免费 PIT 数据**：四家交易所每日公布全部合约结算数据（价、量、持仓），历史可回溯十几年；仓单、会员持仓排名也免费。
- **学术证据相对强**：中国商品期货截面的期限结构（展期收益）、基差动量、持仓变化等因子有多篇论文支持，且与股票市场低相关——这正是 Portfolio 缺的**第二条独立袖子**该长的地方。
- 风险：截面只有 60 个（ML 要更谨慎，A3 一层一模型仍适用）；品种上市时间参差；主力合约切换要处理干净。
- 载体：需要**期货账户**（你开）。研究不需要账户，现在就能开始。
- 顺带：黄金/白银/铜/原油在国内期货里都有（AU/AG/CU/SC）。如果期货截面模型对这些品种有观点，**MT5 的 GOLD/SILVER/COPPER/CrudeOIL 可以作为执行口**（GOLD/SILVER 隔夜费用小）。这是你想做的"MT 黄金原油"唯一说得通的进法：不是在黄金价格上找规律，而是从有截面的市场借信息。

→ **V31 = `CN_FUTURES_XS_V31`**：先设计（数据源 → 主力连续 + 展期 → 特征 → 一个预注册模型 → LS/多头账本 + 实测手续费 → 门）。

### 3. MT5 黄金 / 原油 / 直盘货币 —— 作为研究对象关闭

- 2026-08 至今 20+ 个家族（趋势、反转、残差、跨品种、利率、持仓、EIA、期限结构、波动率、宏观……）全部证伪，V10 的 62 个模型实验 FDR 0/62。V30 补上了"股票 CFD 费率不可行"。
- 更正一处：这家经纪商**有** `GOLD` / `SILVER`（不是 XAUUSD 命名），我下午说"没有黄金符号"是错的；它们过去就是 XA/UM/CM 家族的研究对象，结论不变。
- 判决：**不再直接在这些品种的价格/免费宏观数据上找边**。它们的未来角色只有一个——期货截面模型（上面第 2 条）的执行口。
- 你要求"打破限制"，我已经解除了范围限制（修正 V2）并把解除后能做的事做了（V30）；剩下的限制是**证据**给的，不是我给的。

### 4. 美股 —— 可研究、暂不执行，优先级 3

- 载体：必须是现金股票账户（IBKR 一类），CFD 已判死（V30）。你现在没有。
- 信息：美股的免费 PIT 信息是四个市场里最丰富的（SEC EDGAR 财报按申报日、Form 4 内部人、FINRA 空头利息、13F）。但**无幸存者偏差的价格历史不免费**（免费源只有当前挂牌股）；要做严肃研究得买一份历史宇宙（几百美元级），或先用 EDGAR 里退市公司的申报记录自建宇宙（工作量大）。
- 判决：等 (a) 期货那条跑完、(b) 你决定是否开美股账户，再写合同。不预付。

## 四、关于"财务自由"的算术（不是泼冷水，是让你有正确的期望）

- ML1 全程 CAGR ≈ 13.7%，MaxDD 曾到 −47%（研究期）、−21%（验证/真样本外）。这是**有证据**的数字；任何比它好的数字现在都没有证据。
- 13.7% 复利：翻倍约 5.5 年。¥5M → 10 年后约 ¥18M（如果边不衰减——它可能衰减）。
- 加杠杆不改变夏普，只放大 −47% 那种回撤到爆仓。**不加杠杆**是我不会让步的一条。
- 真正能改变结果的只有一件事：**第二条、第三条独立袖子**（相关 < 0.3），让组合夏普上去、回撤下来。这就是为什么下一刀是期货截面，而不是再挖 A 股或黄金。
