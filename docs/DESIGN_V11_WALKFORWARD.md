# V11.0 MT5 历史回测 + 风控证伪 — Phase 1 Design

> **状态：** 已冻结。  
> **日期：** 2026-08-24

## 1. 目标

用本机 MT5 真 K 线做 **样本内 / 样本外** 回测，加上硬风控。  
结论只许三种：`falsified` / `risk_fail` / `insufficient` / `survived`。  
`survived` = 这次没被证伪，**不是**年化承诺。

## 2. 为什么要改 Worker

Xavier 回测现在收到 `symbol+start` 就**造**一年合成价。若 Master 声称 MT5 回测却不改 Worker，就是假的。

**加法：** `POST /backtest` 可带 `close[]`。有且够长 → 用真收盘价。没有 → 旧合成路径不变。

## 3. 分工

```
Master 拉 D1 close（约 500 根）→ 切 70/30
    → Xavier 回测 Worker 各算一次 RSI（带点差/手续费）
Master 只做判定，不算收益曲线
```

## 4. 风控（写死，不调参刷分）

| 项 | 值 |
|----|----|
| 最少根数 | 200 |
| 样本内比例 | 70% |
| 最少成交 | 两边各 5 |
| 最大回撤 | 25% |
| 成本 | 滑点 10bp + 佣金 5bp |
| 策略 | 现成 `RSI`（不新发明） |

样本外收益 ≤ 0 → 证伪。回撤超限 → 风控淘汰。

## 5. 不做

实盘、自动下单、年化 100%、海量因子、同花顺。
