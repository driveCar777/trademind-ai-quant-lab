# Dashboard — 本机控制台

页面：`index.html`（研究台）、`paper.html`（A 股纸面操作台 V2）、`paper_v1.html`（旧纸面台，只看曲线）。Master 启动后：

- 研究台 `http://127.0.0.1:9000/dashboard`
- 操作台 `http://127.0.0.1:9000/paper`（V26.8 链上名单 + 真实日历上的「今天要做什么」+ 一键后台更新数据 + 成交日志 + 历史每一期 + 规则 FAQ；不发单）。设计见 `docs/research_engine/PAPER_OPS_DESK_V2_DESIGN.md`，接口见 `SPEC.md` §29.5–29.8
- 旧曲线页 `http://127.0.0.1:9000/paper/v1`（研究/验证曲线、资金可调预览）

操作台每日用法：平时不用动；卖出日早上按「卖出清单」卖 → 回来登记；当晚 18:30 后点「更新数据」出名单；买入日早上按「买入名单」买 → 登记。不登记成交就退回 ¥20,000 影子账本。

用法：看节点是否在线 → 选一种计算并「开始计算」→ 点记录看结果，或把数字交给通义千问。

AI 只读输入框里的数字，不会自动拉行情或 Worker 结果。
